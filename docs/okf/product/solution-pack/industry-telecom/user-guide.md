# Telecom industry pack — user guide

The pack has no screens, Pipelines or dashboards of its own. Once a Space's domain profile is `telecom`, Link Analysis in that Space:

- names concepts in telecom terms (nodes read as Subscribers, links as Calls);
- normalises and masks the telecom identifiers (MSISDN, IMSI, IMEI and the others in [architecture](architecture.md));
- offers the four telecom pattern packs and the suggested tools communities, explain and cohesion;
- starts "investigate a number" from an MSISDN with the pack's window and fan-out defaults.

Day-to-day work happens in the paired Space Templates — follow their guides:

- [Telecom fraud user guide](../telco-fraud/user-guide.md)
- [Link Analysis showcase user guide](../la-showcase/user-guide.md)
