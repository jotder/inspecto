# Link Analysis claims showcase — brochure

> **A staged-accident ring behind one garage, one clinic and one lawyer — found among 520 ordinary claims in twelve minutes.**

*Audience: customers, presales and sales. Product Map Item `solution-pack.la-claims` · status **preview**. This is a seeded demonstration Space on synthetic data, not a sold product. Prices are not published here.*

## Who it is for

Insurance special-investigation units and presales teams evaluating Link Analysis for claims fraud.

## The problems it solves

- Showing how shared phones, addresses and providers expose an organised claims ring, while a family sharing a home does not.

## What is included

- Six feeds (claims, parties, policies, provider bills, accident locations, provider directory) landed by six Collectors and Pipelines.
- One link Dataset of seven link kinds and a policy-timing Dataset.
- Link Analysis settings, index-build and detection Jobs, three saved views and three saved Geo Views.
- Five demo users and a role table; a seeding script for Investigations, identity groups and a Case.
