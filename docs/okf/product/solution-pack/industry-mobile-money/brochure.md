# Mobile money industry pack — brochure

> **Link Analysis that speaks mobile money — wallets and agents linked by transfers, cash-in, cash-out and merchant payments.**

*Audience: customers, presales and sales. Product Map Item `solution-pack.industry-mobile-money` · status **ga**. Prices are not published here.*

## Who it is for

Mobile-money fraud, AML and assurance analysts using Link Analysis.

## The problems it solves

- Money flows through agents and wallets in patterns a generic graph does not name.
- Pass-through, layering and structuring must be found by hand.

## What is included

- Mobile-money Entity Types, link kinds and terms.
- Five pattern packs: pass-through, layering chain, inbound collector, circular flow, structuring.
- A domain profile with amount and time hints and suggested tools (scoring, pattern, flow).
- Paired Space templates: [Mobile money](../../solution-pack/mobile-money/brochure.md) and [Link Analysis mobile money](../../solution-pack/la-mobile-money/brochure.md).

## How it fits with the Editions

Included in every Edition, [Basic](../../edition/basic/brochure.md) upwards. Licensed by contract.

## How it works

Select the Mobile Money domain profile for a Space; Link Analysis then uses the wallet and agent vocabulary and offers the money-flow pattern packs.

See it in the Link Analysis mobile money showcase, then apply it to your wallet ledger.
