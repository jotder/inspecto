# Link Analysis audit showcase — brochure

> **Procure-to-pay and the journal as a graph — a fictitious vendor, a shell cluster and split invoices, ending in a Dossier that fails verification if one byte changes.**

*Audience: customers, presales and sales. Product Map Item `solution-pack.la-audit` · status **preview**. This is a seeded demonstration Space on synthetic data, not a sold product. Prices are not published here.*

## Who it is for

Internal audit, finance controls and presales teams evaluating Link Analysis for procure-to-pay and journal risk.

## The problems it solves

- Showing how a vendor sharing a bank account with an employee, split invoices under an approval limit, a single point of control and intercompany round trips appear in a graph.

## What is included

- Five daily-poll feeds (invoices, approvals, vendor master, employee master, journal) with the next month staged.
- Link Datasets for approvals, identity, organisation, journal flow and duplicate payments.
- Link Analysis settings, index-build and detection Jobs, three saved views.
- Five demo users and a role table; a seeding script for Investigations and a Case.
