# Link Analysis mobile money showcase — brochure

> **Seven mobile-money stories — structuring through an agent, a mule chain, a device farm — found in fourteen days of wallet data.**

*Audience: customers, presales and sales. Product Map Item `solution-pack.la-mobile-money` · status **preview**. This is a seeded demonstration Space on synthetic data, not a sold product. Prices are not published here.*

## Who it is for

Presales teams and mobile-money operators evaluating Link Analysis.

## The problems it solves

- Showing how agent-assisted structuring, mule chains and device farms look in a graph, next to a benign high-volume biller.

## What is included

- Three Pipelines (wallet transactions, wallet register, agent register) with 14 landed days and staged next-day files.
- A link Dataset of six link kinds and a masked KYC reference Dataset.
- Link Analysis settings (masking, four-eyes, index, Drafts), index-build and detection Jobs, three saved views.
- Four demo users and a role table; a seeding script for Investigations and a Case.
