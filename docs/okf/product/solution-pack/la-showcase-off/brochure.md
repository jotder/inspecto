# Link Analysis showcase (feature off) — brochure

> **Proof that a feature switched off for a Space is really off — and everything else keeps working.**

*Audience: customers, presales and sales. Product Map Item `solution-pack.la-showcase-off` · status **preview**. This is a seeded demonstration Space on synthetic data, not a sold product. Prices are not published here.*

## Who it is for

Presales and security reviewers who want to see per-Space feature control.

## The problems it solves

- Demonstrating that Link Analysis can be disabled for one Space without affecting the rest of the product.

## What is included

- A Space with the Link Analysis feature disabled (its routes answer "module disabled").
- The same five demo users and roles as the showcase. No feeds, no data.

## How it fits with the Editions

Needs an [Advanced](../../edition/advanced/brochure.md) or [Preview](../../edition/preview/brochure.md) build with demo sign-in. Used beside [Link Analysis showcase](../../solution-pack/la-showcase/brochure.md).

## How it works

Create it next to the showcase Space and sign in as the same persona: Link Analysis is absent here while Pipelines and other screens work normally.

## Next step
