# Link Analysis showcase (feature off) — user guide

Sign in with any of the la-showcase Demo Users ([user guide](../la-showcase/user-guide.md)) and switch to this Space. Link Analysis and Geo are off here: their routes answer 404 `MODULE_DISABLED`, while the rest of the Space still works. There is no data and nothing to investigate; use it to show that the feature is a per-Space switch.
