# Error catalogue

Every refused request answers a v1 error body `{"error": {"errorCode", "message", "recoverable", "correlationId", "details"}}`.
**Branch on `errorCode`, never on the message text.** A `422` adds `error.details.findings[]` — one
`{severity, fieldPath, message, code, guidance}` per problem; fix every `ERROR` finding (its `code` is in the second
table, its `guidance` says what to change at `fieldPath`) and resubmit. `WARNING` findings never block a save.

Most `422`s share the one code `CONFIG_VALIDATION_FAILED`; their `message` names the key and the allowed values.
Quote the `correlationId` when you report a `500`.

## Error codes (every v1 error)

Read from `error.errorCode`. 21 codes.

| Code | Status | Cause | Fix |
|---|---|---|---|
| `MALFORMED_REQUEST` | 400 | The request could not be read: the body is not a JSON object, a required field or query parameter is missing, or a value has the wrong type or format. | Read the message — it names the field and the shape it wants. Send a JSON object body with every required field, then retry. |
| `UNAUTHENTICATED` | 401 | The request carries no credentials, or they are invalid or expired. | Sign in again, or refresh the token or API key the request carries. |
| `PATH_JAIL_VIOLATION` | 403 | A path in the request leaves the folder it must stay in (the config root, the data root or a Space's allowed folders), or a draft names a config file a caller may not reach. | Use a path relative to the Space's own folders, with no '..' and no absolute path outside the allowed roots; for a config reference, name the component (kind/name), not a file. |
| `PERMISSION_DENIED` | 403 | You are signed in, but your role lacks the Capability this route requires, or the object belongs to a Space or share you cannot reach. An agent is also refused routes outside its allowed set. | The message names the Capability. Ask an administrator for a role that holds it, or, for an agent, propose the change for a person to approve instead of calling the route. |
| `MODULE_DISABLED` | 404 | The route belongs to a module that is installed but switched off in this Space. | An administrator switches the module on for the Space (PUT /settings/modules), or use a Space where it is on. |
| `NOT_FOUND` | 404 | Nothing exists at this path or id: a misspelled route, an id that was never created or was deleted, or a name in another Space. | List the collection first (the matching GET) and use an id from it; check the Space in the path. A route of a switched-off module answers MODULE_DISABLED, not this. |
| `METHOD_NOT_ALLOWED` | 405 | The path exists but does not take this HTTP method. | Use the method the API contract (docs/api/openapi-v1.json) lists for this path. |
| `CONFLICT` | 409 | The request clashes with what exists: the name is already taken, the target is used by other configs, or the object is in a state that refuses this action. | Read the message and details: pick another name, or repoint or remove the dependents it lists. Some deletes accept ?force=true when the message says so. |
| `CONFLICT_STALE_VERSION` | 409 | The object changed after you read it: the If-Match version you sent is no longer current, or a concurrent writer kept winning. | GET the object again, re-apply your change to the fresh copy, and resend with its new version or ETag in If-Match. |
| `DEMO_ROSTER_CONFLICT` | 409 | One demo user is defined differently in two Spaces attached to the same demo server. Demo builds only. | Make that user's row in config/demo-users.toon identical in both Spaces, or attach only one of them, then restart the demo server. |
| `PAYLOAD_TOO_LARGE` | 413 | The request body is over the route's size cap (an agent's body is capped at 256 KiB). | Send less: split the change, page an upload, or reference the data by name instead of inlining it. |
| `CONFIG_VALIDATION_FAILED` | 422 | The request parsed but its content is refused: a config that would not load or run, a value out of range, an unknown key, or a reference to something that does not exist. The default code of every 422. | Read error.message and every ERROR in error.details.findings[]: each names its fieldPath, often a code (listed under Config finding codes) and guidance. Fix them all, then resubmit; preview or validate routes check a draft without saving it. |
| `ERR_SAFETY_POLICY_UNREADABLE` | 422 | A Safety Policy file in scope exists but cannot be read as a valid policy, so every gate and run in its scope fails closed. | An operator fixes or removes the Space's config/safety-policy.toon (GET /health names the unreadable file), then retries. |
| `ENTITLEMENT_READ_ONLY` | 423 | The install is read-only: its entitlement expired and the grace period ended, or a trial build has no entitlement. Reads continue. | An administrator installs a renewed entitlement; writes resume without a restart. |
| `RATE_LIMITED` | 429 | Too many expensive requests from you in a short time: your request budget for this route is spent. | Wait the number of seconds in the Retry-After header, then retry. Batch or cache reads instead of repeating them. |
| `INTEGRITY_VIOLATION` | 500 | Stored evidence disagrees with its own recorded hashes, so the store is refused rather than read. | Not fixable from the request. Report it with the correlationId; an operator restores the store from backup or investigates the tampering. |
| `INTERNAL` | 500 | The server failed while answering — a defect or an outage, not a problem with the request. | Retry once. If it repeats, report it with the correlationId from the body; the server log carries the cause under that id. |
| `NOT_SUPPORTED` | 501 | The route exists but cannot do this for this target on this host — for example run-to-here on a Collector that does not read files. | Use the alternative the message names, or a different target. |
| `CAPABILITY_UNAVAILABLE` | 503 | The route needs a module or a service this install does not have — not installed in this edition, or a dependency (such as the run lease database) is down. | Check GET /health/details and the edition. Install or enable the module, or wait for the dependency; this is not fixed by changing the request. |
| `CONTROL_PLANE_READ_ONLY` | 503 | Config writes are switched off on this server: it was started without a config write root. | An operator restarts the server with -Dassist.write.root=<config folder>. Reads keep working meanwhile. |
| `STORE_BUSY` | 503 | A shared store is locked by another request or server and did not free within the bounded wait. | Retry after a short wait. Nothing in the request needs to change. |

## Pipeline graph codes

Read from `findings[].code of a Pipeline graph validate or save`. 20 codes.

| Code | Status | Cause | Fix |
|---|---|---|---|
| `CYCLE` | — | Data edges form a loop; a Pipeline must be a directed graph without cycles. | Remove one edge of the loop the message lists. |
| `DANGLING_FROM` | — | An edge starts at a node id the graph does not have. | Correct the edge's from: to an existing node id, or add the node. |
| `DANGLING_TO` | — | An edge points at a node id the graph does not have. | Correct the edge's to: to an existing node id, or add the node. |
| `DUPLICATE_NODE` | — | Two nodes in the graph share one id. | Give every node a unique id, and update the edges that point at the renamed one. |
| `EMPTY_GRAPH` | — | The Pipeline graph has no nodes. | Add at least an entry node and the Steps it feeds. |
| `ILLEGAL_ACCEPT` | — | An edge carries data into a node type that does not accept data. | Point the edge at a node that accepts it, or use a relationship the target accepts (the message lists them). |

| `ILLEGAL_PAIRING` | — | An outcome or route edge targets a node that can neither accept that relationship nor read it as rows — an entry node, or a specialised consumer fed the wrong stream. | Point the edge at a Step or sink that takes rows, or at a consumer of that relationship. |
| `JOIN_KEYED_INVALID` | — | A keyed transform.join's settings cannot run, judged from the config alone. | Correct the key settings the message names. |
| `JOIN_MATCH_UNKNOWN` | — | A transform.join node's match: is not a mode the join runs. | Use one of the match modes the message lists. |

## Adding a code

A new code constant, or a `new ApiException(status, CODE, …)` naming a code this page does not list, fails
`node tools/render-error-catalogue.mjs --check` (pre-commit and CI). Add its cause and fix to `tools/error-catalogue-entries.json`, then run `node tools/render-error-catalogue.mjs --write`.
Codes are API: never renamed, never reused for another meaning.
