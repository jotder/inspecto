# Platform — features

**Product Map Item:** [`layer.platform`](../../../../../product-map/layer/platform.toon) · **Status:** ga · **Availability:** Platform base — present in every Edition.

## What it is

The platform is the framework-free Java engine and control plane every Edition shares: JDK HttpServer, manual wiring, ServiceLoader SPIs and embedded DuckDB. Editions are build flavors of it, never branches.

## Who benefits

Architects evaluating the product, and administrators who install and run it.
