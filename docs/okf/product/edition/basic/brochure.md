# Inspecto Basic — brochure

> **Land your files, check them, explore them as a graph — on one machine, with nothing else to install.**

*Audience: customers, presales and sales. Product Map Item `edition.basic` · status **ga**. Prices are not published here.*

## Who it is for

A single analyst, a team lead running a pilot, or a presales engineer who needs a working data-assurance desk today: no sign-in server, no database, no cluster.

## The problems it solves

- Files arrive late, half-delivered or malformed, and nobody notices until a report is wrong.
- Checks live in spreadsheets and one-off scripts that only one person understands.
- Relationships between accounts, numbers or parties are hidden in flat tables.

## What is included

- The core platform: Collectors, Pipelines with typed schemas and quality Expectations, Datasets, SQL, Alert Rules, KPIs and dashboards.
- The standard connectors module.
- Link Analysis explorer ([Link Analysis](../../addon/linkAnalysis/index.md) Add-on, explorer part): graph studio, paths and neighbours, pattern packs, geo map, Entity Lists, identity resolution, Entity profile pages, PNG/CSV export.
- Both industry vocabularies for Link Analysis (Telecom, Mobile Money).
- Content packs: [Orders starter](../../solution-pack/orders-starter/brochure.md), [Business assurance](../../solution-pack/business-assurance/brochure.md) and [Link Analysis daily feed](../../solution-pack/la-daily-feed/brochure.md).
- Audit log, recorded and readable.

## How it fits with the Editions

Basic is the entry Edition and the base the others build on: [Standard](../../edition/standard/brochure.md) includes everything in Basic. Basic runs without sign-in, so masking is display-only and there are no Investigations, Dossiers, Drafts or four-eyes — those start at Standard. Moving up is a different build of the same product, not a migration: your Spaces and configuration carry over.

## How it works

Inspecto is one self-contained application. A Collector picks up files from a folder, a Pipeline validates them against a schema and lands them as a Dataset, and Expectations and Alert Rules watch every delivery. Everything is plain configuration you can read, review and version. Open the Link Analysis explorer on any Dataset to see who is connected to whom.

## Next step

Ask for a Basic build and start from the Orders starter template — a first live dashboard takes minutes. When you need sign-in, teams or Investigations, talk to us about Standard.
