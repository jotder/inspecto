# Inspecto Preview — brochure

> **Everything Inspecto has, in one build — to evaluate, demonstrate and try what is coming next.**

*Audience: customers, presales and sales. Product Map Item `edition.preview` · status **ga**. Preview is an evaluation and incubation build, not a production tier. Prices are not published here.*

## Who it is for

Evaluators, presales demonstrations and design partners who want to see the whole product, including incubating features, before choosing an Edition.

## The problems it solves

- Choosing an Edition before you have seen the full product.
- Running the seeded Link Analysis showcases with ready-made demo users.

## What is included

- Every module — today identical to Advanced, and any incubation-only module lands here first.
- Demo sign-in for the showcase Spaces (personas such as analyst, manager and reviewer).
- All solution packs, including the Link Analysis showcases: [Link Analysis showcase](../../solution-pack/la-showcase/brochure.md), [mobile money](../../solution-pack/la-mobile-money/brochure.md), [claims](../../solution-pack/la-claims/brochure.md) and [audit](../../solution-pack/la-audit/brochure.md).

## How it fits with the Editions

Preview includes [Advanced](../../edition/advanced/brochure.md). It is for testing and evaluation; for production, buy [Basic](../../edition/basic/brochure.md), [Standard](../../edition/standard/brochure.md) or [Advanced](../../edition/advanced/brochure.md).

## How it works

Install the Preview build, create a Space from a showcase template, run its seeding step, and sign in as one of the demo personas to walk the scripted story.

## Next step

Ask your Inspecto contact for a Preview build and a guided showcase walk-through.
