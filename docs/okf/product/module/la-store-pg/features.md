# Link analysis PostgreSQL store — features

**Product Map Item:** [`module.la-store-pg`](../../../../../product-map/module/la-store-pg.toon) · **Status:** ga · **Availability:** Optional module, staged from Advanced and every higher Edition (`offerings/advanced.toon`). Add-on: [linkAnalysis](../../addon/linkAnalysis/index.md).

## What it is

The Link Analysis PostgreSQL store provides an `InvestigationStoreProvider` backed by PostgreSQL. It lets investigations be kept in a shared database instead of local files.

## What this enables

- Larger teams can share investigations through PostgreSQL on Advanced and Preview
