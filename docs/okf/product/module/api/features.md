# Public API annotations — features

**Product Map Item:** [`module.api`](../../../../../product-map/module/api.toon) · **Status:** ga · **Availability:** Platform base — present in every Edition (Basic, Standard, Advanced, Preview).

## What it is

Public API annotations mark which Java surfaces are intended to stay stable for integrators. The `@PublicApi` marker states intent; the release baseline and draft release notes live in this hub.

## What this enables

- Integrators can see which extension surfaces are meant to be stable and read what changes in the pending major release — [plan-api-stability](plan-api-stability.md)
