# SQL guard and helpers — features

**Product Map Item:** [`module.sql`](../../../../../product-map/module/sql.toon) · **Status:** ga · **Availability:** Platform base — present in every Edition (Basic, Standard, Advanced, Preview).

## What it is

The SQL guard and helpers check every SQL statement the platform runs on a user's behalf. It is the shared guard used by queries, Pipelines and BI.

## What this enables

- Customers can let analysts write SQL without opening the host to arbitrary statements — the guarded execution stack is described in [plan-data-plane](../../layer/platform/plan-data-plane.md)
