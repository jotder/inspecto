# Kafka stream connector — features

**Product Map Item:** [`module.connectors-kafka`](../../../../../product-map/module/connectors-kafka.toon) · **Status:** ga · **Availability:** Optional module, staged from Standard and every higher Edition (`offerings/standard.toon`). Add-on: [premiumConnectors](../../addon/premiumConnectors/index.md).

## What it is

The Kafka stream connector adds the `kafka` scheme to the Collector connector family. It is the premium streaming counterpart to the file and database connectors.

## Who benefits

Customers whose records arrive on Kafka topics rather than as files.

## Key capabilities

- Kafka as a Collector connector scheme alongside sftp/ftp/db/object storage — [Connectors spec](../connectors/spec-connectors.md)
