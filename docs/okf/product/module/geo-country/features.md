# MaxMind geo-country resolver — features

**Product Map Item:** [`module.geo-country`](../../../../../product-map/module/geo-country.toon) · **Status:** ga · **Availability:** Optional module, staged from Standard and every higher Edition (`offerings/standard.toon`).

## What it is

The MaxMind geo-country resolver maps IP addresses to countries through the `GeoCountryResolver` contract. It is a provider other features call, not a screen of its own.

## What this enables

- Records can be enriched with a country derived from an IP address, through one resolver contract any feature can call
