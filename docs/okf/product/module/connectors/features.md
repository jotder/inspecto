# Collector and export connectors — features

**Product Map Item:** [`module.connectors`](../../../../../product-map/module/connectors.toon) · **Status:** ga · **Availability:** Optional module, staged from Basic and every higher Edition (`offerings/basic.toon`).

## What it is

Collector and export connectors bring files and tables in from remote systems and push results out. The network-facing schemes live here, kept out of the core.

## Who benefits

Integration engineers onboarding new feeds, and operators who verify and run them.

## Key capabilities

- Registered schemes sftp, ftp, ftps, db, s3, azure and gcs, with SSH tunnelling and proxy dial-through — [spec-connectors](spec-connectors.md)
- Schema-driven connection workbench with test, probe and sample — [user-guide-connections](user-guide-connections.md)
- Copy-pasteable connection profiles and a verification sequence — [admin-guide-connectors-runbook](admin-guide-connectors-runbook.md)
- Warehouse export targets — [plan-warehouse-targets](plan-warehouse-targets.md)
