# Geo and link adapters over platform data — features

**Product Map Item:** [`module.geo-link`](../../../../../product-map/module/geo-link.toon) · **Status:** ga · **Availability:** Optional module, staged from Basic and every higher Edition (`offerings/basic.toon`). Add-on: [linkAnalysis](../../addon/linkAnalysis/index.md).

## What it is

Geo and link adapters connect the Link Analysis studio to platform data: Datasets, Cases, Collector coverage and measures. They power the offline geographic investigation studio on a fully bundled basemap.

## Who benefits

Investigators who need to see where activity happens and how entities connect.

## Key capabilities

- Offline map over Datasets with intelligence toolboxes and saved Geo Views — [user-guide-geo-map](user-guide-geo-map.md)
- Investigation measures, data changes and Alert Rules from an investigation — [feature-db](feature-db.md)
