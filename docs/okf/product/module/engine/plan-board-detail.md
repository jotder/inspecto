- **Interrupting one ingest unit mid-write on graceful stop** — ⛔ decided 2026-10-18 under operator delegation (closes `HA-CANCEL-RESIDUALS-1` (3)): a cancel stops between Consignments, between chunks of a chunked file (the shared write checkpoint runs per chunk, pinned by `RunCancellationTest`) and between remote-fetch files, but not inside one DuckDB `COPY` or one file fetch. Trigger: a measured graceful stop that routinely hits the 10 s deadline, together with a run-unique staging-then-rename output path. → `okf/product/module/elt/spec-ingest.md` § Failover
