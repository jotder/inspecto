# Demo authenticator — features

**Product Map Item:** [`module.demo-auth`](../../../../../product-map/module/demo-auth.toon) · **Status:** ga · **Availability:** Staged only in a `-DemoAuth` demo bundle, replacing OIDC; CI fails if it leaks into a non-demo bundle ([Identity and Access](../access/features-access.md)).

## What it is

The demo authenticator lets a visitor pick a Demo User and sign in without a password or identity provider. It exists only for evaluation and demo bundles.

## What this enables

- Prospects and trainers can run a full offline demo with realistic roles and no IAM setup — [admin-guide-local-testing](../../layer/platform/admin-guide-local-testing.md)
