**Rubric:**
- R1 Compact: label ≤ 3 words, tooltip one line (≤ ~10 words), hint ≤ 2 short sentences, section description ≤ 1 sentence; no filler.
- R2 Plain words: no internal or API names, ticket ids, code terms, or unexplained jargon and badges.
- R3 Canonical vocabulary per `docs/GLOSSARY.md`; one concept, one word across the Studio.
- R4 Consistent form: sentence case, "…" only on items that open a dialog, British spelling, no trailing period on labels and tooltips, one dash style.
- R5 Accurate: matches what the control does and where things are; no stale references; no contradictions.
- R6 Helpful states: every disabled control says why; empty states say what to do next; errors say what happened and what to do, never raw server or capability strings.
- R7 Accessible names: icon buttons have an aria-label equal to the tooltip; no two actions share a name; no duplicate names for one field.
- R8 Grammar and typos: broken sentences, double spaces, placeholders rendered empty.

Severity: H = wrong, misleading or broken text, or a blocked action with no reason; M = unclear, inconsistent or verbose; L = polish. No real data values appear here; examples are described, not copied.
