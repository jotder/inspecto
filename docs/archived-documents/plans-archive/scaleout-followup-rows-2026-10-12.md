## Rows to paste

- **P2** · `SCALEOUT-OBJSTORE-DATABASE-DIR-1` — **`dirs.database` cannot be an `s3://` URI: path containment refuses any URI, so the Enterprise lakehouse cannot keep its DuckDB data on object storage.** Evidence: `ConfigSafetyValidator.java:497` throws "is a URI, not a filesystem path"; `PathJail.java:48-78` documents that an object-store path "needs its own containment rule" and none exists; `dirs.database` is in the jailed set at `ConfigSafetyValidator.java:68`; the write-side client is `PartitionWriter` only (DuckLake `data_path`). Decision owed: the containment rule for a URI (allow-list of bucket/prefix per Space vs. refuse and keep local) and whether `AIRGAP-S3-EXTENSIONS-1` (packaging `httpfs`) is a precondition. Scope: `PathJail` URI branch + validator + tests that a URI outside the Space prefix is refused; plan section 5.4 bullet 6.
- **P2** · `SCALEOUT-HELM-NPOD-1` — **The only Helm chart is a replicas-1 StatefulSet; there is no N-pod topology, no ingress template, no per-pod Space assignment.** Evidence: `deploy/helm/inspecto/values.yaml:3-7` ("NOT MULTI-REPLICA SAFE", replicas pinned in the template); `deploy/helm/inspecto/templates/` holds only `statefulset`, `service`, `secret`, `_helpers`, `NOTES`; no `ingress` anywhere. Decision owed: D16 (ingress generated from the Space-to-Pod map, SPA served off the pods) before the chart can route. Scope: a values-gated N-pod mode (`pod ordinal` property, Postgres run lease, shared catalog) and a generated ingress; the plan places it last in phase C. Depends on `SCALEOUT-D14-D16-DECISIONS-1`.
- **P2** · `SCALEOUT-D14-D16-DECISIONS-1` — **Three operator decisions are unsigned and block the rest of phase C.** Evidence: plan section 9 rows D14 (inbox-sharing group as the unit instead of the Space), D15 (split-brain posture; its idempotency precondition is now partly built, see the write-path row), D16 (ingress path routing, `/spaces` from the map, SPA off the pods). `SPACES-FROM-PARTITION-MAP-1` is already blocked on D16. Decision owed: sign, refine or decline each; recommendation in the plan is yes to D14 and D16, and the D15 question re-posed as "fund the precondition". Scope: decision only; then unblock `SPACES-FROM-PARTITION-MAP-1`, `SCALEOUT-U1-REMOTE-ACQUIRE-1` and the Helm row.
- **P3** · `SCALEOUT-U1-REMOTE-ACQUIRE-1` — **Remote acquisition (U1) is not distributed: two pods would both fetch the same remote file.** Evidence: the precondition exists (`AcquisitionLedgers.java` selects a Postgres ledger via `-Dacquire.ledger.backend=db`; `DbAcquisitionLedger.record`), but `StabilityGate.java:76,80` keeps its state in a per-process `ConcurrentHashMap` (`SHARED`, keyed by Space id), and the check-then-record window in the ledger has no claim. Decision owed: depends on D14; whether the claim is a ledger row with a lease or an advisory step. Scope: a claim surface in the ledger, a stability gate that reads shared state, a two-process test.
- **P3** · `SCALEOUT-LIVE-HALVES-1` — **The live halves of spike S5 (`pg_duckdb` view queried from `psql`) and of an end-to-end S1 run across N processes are still owed; D13 has no code.** Evidence: no `pg_duckdb` reference in any `.java`/`.toon` file (grep, 2026-10-12); plan sections 6 and 10 record "live half owed". Decision owed: none, only an environment; the answer feeds D13's deployment precondition. Scope: run unattended per the plan's section 9 recipe and record the measured result.
- **P3** · `SCALEOUT-WRITEPATH-IDENTITY-AUDIT-1` — **Whether every write path keys on the stable Consignment id is unverified.** Evidence: built: `ConsignmentId.java:72` (content digest), `DbFileStageStore` `UNIQUE (batch_id, source_id, relative_path, stage)` with `ON CONFLICT DO NOTHING`, `DbConsignmentOutputStore.java:127` `UNIQUE (consignment_id, path, run_id)`.
