Pipeline · Orders (daily CSV)
Five steps. Each one answers one question.
Collect
Which files should we pick up, and from where?
Folder or connection · file pattern · how often
Parse
Redesigned
How do we read the file, and what columns come out?
Delimiter, quotes, header · bad-row handling · column types · tested on one sample
Transform
New
What should each field look like when it comes out?
Rename · tidy · change type · calculate · leave out · one row per field
Filter
Which rows do we keep?
Kept rows → next step
Dropped rows → review bin (never lost)
Store
Where does it land, and how is it organised?
Destination · split by (e.g. month) · compression · keep for
Every step can be tried on the sample you gave in Parse — you see real rows before anything runs for real.
