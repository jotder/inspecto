Every select item becomes a row. An expression the catalog recognises gets its plain-language operation back; anything else stays a Custom SQL row with the expression verbatim. Nothing is lost in either direction.

When fields cannot show it
A WHERE, JOIN, CTE, subquery or SELECT * is not a projection. The Fields tab stays visible but disabled, with one line: "This Step filters or joins. Fields shows projections only; move the filter to a Filter Step to edit it as fields." The SQL is never altered by looking.
