#   steps[1]: - dedup: { keys[1]: ORDER_ID, order_by: "ORDER_DATE DESC" }

# (a status change), so 12 rows land and the rollup holds 9 unique orders — the NEWEST version of each.
# An optional scope: (a time window) turns this into a cross-Consignment dedup backed by a durable ledger.
